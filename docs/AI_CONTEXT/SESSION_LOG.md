## 2026-10-11 — Devin, TitleTooltip flicker fix (closest selector bug)
**Changed:** `TitleTooltip` hovered element had its `title` moved to `data-tt` — but the mouseover selector only matched `[title]`, so any intra-element movement (icon ↔ padding on a button) made `closest('[title]')` return null → restore() killed the tooltip and re-armed it on the next event: visible flicker/stickiness app-wide, worst on icon-only buttons.
